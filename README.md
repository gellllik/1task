Задачи на день
Мини-приложение для управления задачами с календарём, приоритетами, архивом и профилем пользователя

1. Что необходимо для запуска:
- OpenServer (OSPanel) — скачать с [ospanel.io](https://ospanel.io/).
- PHP 8.4 (входит в OpenServer).
- MySQL 5.7 или выше (входит в OpenServer).
- Расширения PHP: `pdo`, `pdo_mysql`, `mbstring`, `json`
- Любой современный браузер.

2. Как установить и запустить приложение
Шаг 1. Установить OpenServer
1. Скачать с ospanel.io и распаковать в папку без пробелов и русских букв.
2. Запустить `OSPanel.exe` от имени администратора.
3. Иконка появится в трее.
Шаг 2. Разместить проект
В OpenServer есть папка `home` — в ней хранятся все проекты.
В папку `home` нужно положить основную папку проекта `task`.
Шаг 3. Настроить, чтобы OpenServer увидел проект
Внутри папки `.osp` есть файл настроек. Его нужно открыть блокнотом и проверить, что в самом верху написано имя основной папкив квадратных скобках:
- `[task]` — имя проекта. Должно совпадать с именем папки
  в `home`. Если папка называется `task` — пишем `[task]`.
- `php_engine` — версия PHP (8.4).
- `web_root` — какая папка является корнем сайта
  (`public`)
Именно после этого OpenServer увидит проект и покажет его
в своём меню.
Шаг 4. Запустить сервер
Клик по иконке в трее → Запустить. 
Индикатор станет зеленого цвета.
Шаг 5. Открыть в браузере
1. Кликнуть по иконке OpenServer в трее (рядом с часами)
2. В открывшемся меню выбрать название своего сайта —
Task.
3. В подменю выбрать «Открыть в браузере».
4. Браузер откроется автоматически и загрузит приложение.
Дополнительно вводить адрес вручную не требуется —
OpenServer сам подставляет корректный адрес и порт.
Шаг 6. Создать аккаунт
Открыть `http://task/register.php` → заполнить форму → после
успешной регистрации откроется главная страница.

3. Как подготовить хранилище данных
Создать базу данных
1. Трей OpenServer → Дополнительно → phpMyAdmin.
Откроется `http://localhost/phpmyadmin/`.
2. Логин: `root`, пароль: введите свой пароль для входа.
3. Вкладка SQL → вставить содержимое файла `bd.sql` → вперёд.
Скрипт создаст:
- базу данных `bd-task` с кодировкой `utf8_general_ci`;
- таблицы `users`, `tasks`, `archive`.
Настроить подключение к БД
1. В папке `public/` скопировать `db.example.php` → `db.php`.
2. Открыть `db.php` и указать свои данные MySQL:
Проверить
Открыть `http://task/` — должна появиться страница входа.
Если нет — проверить, что MySQL запущен и данные в `db.php` верны.

4. Какие возможности реализованы
Аутентификация
- Регистрация пользователя с валидацией (ФИО, телефон, должность, логин, пароль)
- Вход по логину и паролю (пароль хешируется через `password_hash`).
- Защита страниц от неавторизованного доступа (`requireAuth`).
- Выход из системы.
Работа с задачами
- Просмотр списка всех задач.
- Создание задачи (название, комментарий, приоритет, дата).
- Редактирование названия, описания, приоритета и даты.
- Удаление с подтверждением — задача уходит в архив.
- Переключение статуса: Актуальная ↔ Выполненная.
- Цветовое отличие: жёлтые карточки — актуальные, голубые — выполненные.
Календарь
- Календарь на месяц с разбивкой по дням.
- Подсветка сегодняшнего дня и выбранной даты.
- Точка на днях, где есть задачи.
- Клик по дню показывает задачи этого дня.
- Переключение месяца кнопками ‹ ›.
Фильтр и поиск
- Фильтр по статусу: Все / Актуальные / Выполненные.
- Поиск по названию задачи.
- Поиск и фильтр работают совместно (можно искать только среди актуальных).
Приоритеты
- Низкий (зелёный бейдж).
- Средний (жёлтый бейдж).
- Высокий (красный бейдж).
Архив
- Список всех удалённых задач.
- Для каждой хранится дата выполнения, старый статус, дата удаления.
- Восстановление задачи одной кнопкой.
- Удаление навсегда.
- Полная очистка архива.
- Поиск и сортировка (по названию).
Профиль пользователя
- Просмотр своих данных.
- Загрузка фотографии профиля (JPG, PNG, GIF, до 2 МБ).
- Фото отображается в шапке сайта на всех страницах.
- Редактирование данных: ФИО, логин, должность, дата рождения, город,
  контакты (телефон, email, Max), описание «О себе».
- Удаление аккаунта.
Дополнительно
- Валидация полей при создании и редактировании.
- Введённые пользователем данные не теряются при ошибке.
- Адаптивная верстка (работает на телефоне).


5. Известные ограничения и незавершённые части
Ограничения
- Авторизация упрощена — нет подтверждения email, восстановления
  пароля, ролей и прав доступа.
- Один список задач на пользователя — общей доски нет.
- Фото профиля хранится в базе данных как base64-строка,
  ограничение — 2 МБ на файл.
- `db.php` создаётся вручную из шаблона `db.example.php`.
- Совместное редактирование одной задачи не блокируется —
  если открыть одну задачу в двух вкладках, изменения сохранятся
  по принципу «последний победил».
- Дизайн минималистичный — без сложных анимаций.
Что не реализовано:
- Уведомления и напоминания о задачах.
- Прикрепление файлов к задачам.
- Общий доступ к задачам между пользователями.
- Экспорт задач в CSV или Excel.
- Тёмная тема.
